## 🚨 الإبلاغ عن ثغرة أمنية / Reporting a Vulnerability

إذا اكتشفت ثغرة أمنية، نطلب منك عدم الإفصاح عنها علناً حتى نتمكن من معالجتها.

If you discover a security vulnerability, we ask that you do not disclose it publicly until we can address it.

### كيفية الإبلاغ / How to Report

يرجى إرسال تقرير الثغرة الأمنية عبر إحدى الطرق التالية:

Please send your security vulnerability report via one of the following methods:

1. **GitHub Security Advisories** (الطريقة المفضلة / Preferred method):
   - انتقل إلى / Go to: https://github.com/ZOOKA-AI/studio/security/advisories
   - انقر على "Report a vulnerability" / Click "Report a vulnerability"
   - املأ النموذج بالتفاصيل / Fill out the form with details

2. **البريد الإلكتروني / Email**:
   - أرسل إلى / Send to: security@zooka.ai (if available)
   - استخدم موضوع / Use subject: `[SECURITY] Firebase Studio Vulnerability Report`

### ما يجب تضمينه / What to Include

يرجى تضمين المعلومات التالية في تقريرك:

Please include the following information in your report:

- **وصف الثغرة** / **Vulnerability Description**: وصف تفصيلي للثغرة / Detailed description of the vulnerability
- **خطوات إعادة الإنتاج** / **Steps to Reproduce**: كيفية إعادة إنتاج الثغرة / How to reproduce the vulnerability
- **التأثير المحتمل** / **Potential Impact**: ما هو التأثير المحتمل للثغرة / What is the potential impact of the vulnerability
- **الحلول المقترحة** / **Proposed Solutions**: أي حلول مقترحة (اختياري) / Any proposed solutions (optional)
- **معلومات الاتصال** / **Contact Information**: كيف يمكننا التواصل معك / How we can contact you

### ما يمكن توقعه / What to Expect

- **الإقرار** / **Acknowledgment**: سنقر باستلام تقريرك خلال 48 ساعة / We will acknowledge receipt of your report within 48 hours
- **التقييم** / **Assessment**: سنقيم الثغرة ونحدد خطورتها / We will assess the vulnerability and determine its severity
- **الإصلاح** / **Fix**: سنعمل على إصلاح الثغرة في أقرب وقت ممكن / We will work on fixing the vulnerability as soon as possible
- **الإفصاح** / **Disclosure**: سنعلمك عند إصدار الإصلاح / We will notify you when the fix is released

### التقدير / Recognition

نحن نقدر جهود الباحثين الأمنيين ونعترف بمساهماتهم:

We appreciate the efforts of security researchers and acknowledge their contributions:

- سيتم ذكر اسمك في ملف SECURITY.md (إذا رغبت) / Your name will be mentioned in SECURITY.md (if you wish)
- سيتم الاعتراف بك في ملاحظات الإصدار / You will be acknowledged in release notes
- نحن ممتنون لمساهمتك في تحسين أمان المشروع / We are grateful for your contribution to improving project security

## 🛡️ أفضل الممارسات الأمنية / Security Best Practices

### للمطورين / For Developers

- تجنب تضمين المفاتيح السرية في الكود / Avoid including secret keys in code
- استخدم متغيرات البيئة للبيانات الحساسة / Use environment variables for sensitive data
- قم بتحديث التبعيات بانتظام / Update dependencies regularly
- راجع تحذيرات Dependabot و CodeQL / Review Dependabot and CodeQL warnings

### للمستخدمين / For Users

- استخدم أحدث إصدار من المشروع / Use the latest version of the project
- لا تشارك مفاتيح API الخاصة بك / Don't share your API keys
- راجع سجل التغييرات للتحديثات الأمنية / Review changelog for security updates
