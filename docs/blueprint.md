# **App Name**: Royal Clean Dashboard

## Core Features:

- Role-Based Access: Different interfaces for admin, supervisor, and worker roles.
- Supervisor Dashboard: A dashboard tailored for supervisors with key metrics and quick actions.
- Daily Report Wizard: A step-by-step wizard for supervisors to easily log daily activities.
- Task Scheduling: Supervisors can schedule and assign tasks to workers with notifications.
- Material Tracking: Track the materials used in each daily report and automatically deduct from inventory. Use tool to consider when this information is valuable in report generation
- Image Uploads: Upload before and after images for each task to visually document progress.
- Report Archiving and Search: Archive daily reports with advanced search capabilities for easy retrieval.

## Style Guidelines:

- Primary color: Deep royal blue (#4169E1) to evoke trust and professionalism.
- Background color: Light blue (#E6EBF5) to provide a clean and calming backdrop.
- Accent color: Vibrant orange (#FF7F50) for highlighting key actions and notifications.
- Body font: 'PT Sans', a modern sans-serif font, used for body text and readability.
- Headline font: 'Space Grotesk', a modern sans-serif font, used for clear, professional headlines.
- Use clean, modern icons to represent different tasks and actions within the dashboard.
- A dashboard-style layout with clear sections for appointments, tasks, and quick actions. Prioritize mobile responsiveness for on-the-go access.
- Subtle animations and transitions to provide feedback and enhance user experience when navigating and completing actions.
