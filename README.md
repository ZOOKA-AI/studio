## 🚀 البدء السريع

### المتطلبات
- Node.js 20+
- npm أو yarn

### التثبيت

```bash
# Clone the repository
git clone https://github.com/ZOOKA-AI/studio.git
cd studio

# Install dependencies
npm install

# Run development server
npm run dev
```

الموقع سيعمل على: http://localhost:9002

### البناء للإنتاج

```bash
# Build for production
npm run build

# Start production server
npm start
```
