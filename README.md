### Quick Setup

1. Copy `.env.example` to `.env.local` and add your Supabase credentials
2. Follow the [Supabase Setup Guide](./docs/supabase-setup.md) for detailed instructions
3. Run migrations from the `supabase/migrations/` directory

For more information, see the [Supabase Setup Guide](./docs/supabase-setup.md).
