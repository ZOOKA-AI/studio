## 📖 نظرة عامة

**ZOOKA-AI Studio** هو مشروع مفتوح المصدر يجمع بين قوة الذكاء الاصطناعي وتطوير الويب الحديث لبناء تطبيقات ذكية ومبتكرة.

### ✨ المميزات الرئيسية

- 🤖 **تكامل AI متقدم** - دعم كامل لنماذج الذكاء الاصطناعي الحديثة
- ⚡ **أداء عالي** - مبني على Next.js 14 مع TypeScript
- 🎨 **واجهة مستخدم حديثة** - تصميم متجاوب مع TailwindCSS
- 🔄 **أتمتة ذكية** - تكامل مع n8n وأدوات الأتمتة
- 🐳 **سهولة النشر** - دعم Docker و Kubernetes
- 📦 **جاهز للإنتاج** - CI/CD متكامل

## 🚀 البدء السريع

### المتطلبات

- Node.js 18+ 
- npm أو yarn
- Docker (اختياري)

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/ZOOKA-AI/studio.git
cd studio

# تثبيت الحزم
npm install

# نسخ ملف البيئة
cp .env.example .env.local

# تشغيل خادم التطوير
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

### باستخدام Docker

```bash
# بناء الصورة
docker build -t zooka-ai-studio .

# تشغيل الحاوية
docker run -p 3000:3000 zooka-ai-studio
```

أو باستخدام Docker Compose:

```bash
docker-compose up
```
