## 🌟 Royal Clean Dashboard

**Royal Clean Dashboard** is a comprehensive business management application designed for professional cleaning companies. Built with Next.js 15, TypeScript, and Firebase, it provides a powerful, bilingual (Arabic/English) interface for managing your cleaning business operations.

### ✨ Key Features

- 📊 **Real-time Dashboard**: Monitor business metrics and KPIs
- 📅 **Appointment Management**: Schedule and track client appointments
- 📝 **Daily Reports**: Detailed work reports with AI-powered summaries
- ✅ **Task Management**: Assign and track tasks efficiently
- 👥 **Worker Management**: Manage team members and assignments
- 📦 **Inventory Tracking**: Monitor materials and equipment
- 🤖 **AI Integration**: Google Genkit for intelligent suggestions and automation

### 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/ZOOKA-AI/studio.git
cd studio

# Install dependencies
npm install

# Set up environment variables (see DEVELOPER_GUIDE.md)
cp .env.example .env.local

# Start development server
npm run dev
```

Visit [http://localhost:9002](http://localhost:9002) to see your application.

### 🛠️ Tech Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: TailwindCSS + shadcn/ui
- **Database**: Firebase Firestore
- **AI**: Google Genkit with Gemini models
- **Forms**: React Hook Form + Zod
- **UI Components**: Radix UI
