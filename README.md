## <a name="english"></a>🌟 English

### Overview

Firebase Studio is a modern, open-source Next.js starter template that integrates Firebase services with AI capabilities powered by Google's Genkit. This project aims to provide developers with a solid foundation for building AI-powered web applications.

### ✨ Features

- ⚡ **Next.js 15.3** with Turbopack for fast development
- 🔥 **Firebase Integration** for authentication, database, and hosting
- 🤖 **AI Capabilities** with Genkit and Google Generative AI
- 🎨 **Modern UI** with Tailwind CSS and Radix UI components
- 📝 **TypeScript** for type-safe development
- 🎯 **Form Handling** with React Hook Form and Zod validation
- 📊 **Data Visualization** with Recharts
- 🌙 **Responsive Design** optimized for all devices

### 🚀 Getting Started

#### Prerequisites

- Node.js 20+ 
- npm or yarn
- Firebase account

#### Installation

1. Clone the repository:
```bash
git clone https://github.com/ZOOKA-AI/studio.git
cd studio
```

2. Install dependencies:
```bash
npm install
```

3. Set up your environment variables (create `.env.local`):
```env
# Add your Firebase configuration here
```

4. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:9002`

### 📦 Available Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
- `npm run typecheck` - Run TypeScript type checking
- `npm run genkit:dev` - Start Genkit AI development server
- `npm run genkit:watch` - Start Genkit with watch mode
