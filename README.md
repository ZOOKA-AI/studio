## 🚀 النشر التلقائي (Automatic Deployment)

تم إعداد هذا المشروع للنشر التلقائي على GitHub Pages. عند كل تحديث لفرع `main`، سيتم:

1. بناء المشروع تلقائيًا باستخدام `npm run build`
2. نشر الملفات الناتجة إلى GitHub Pages

### تفعيل GitHub Pages

لتفعيل GitHub Pages للمرة الأولى، اتبع الخطوات التالية:

1. انتقل إلى صفحة المستودع على GitHub
2. اذهب إلى **Settings** > **Pages**
3. في قسم **Source**، اختر **GitHub Actions**
4. بعد أول عملية نشر ناجحة، سيكون الموقع متاحًا على: `https://zooka-ai.github.io/studio`

### البناء المحلي

لبناء المشروع محليًا:

```bash
npm install
npm run build
```

سيتم إنشاء الملفات الثابتة في مجلد `out/`.
